# பெரிய சைஸ் பித்தளை குடம் வாங்கும்போது என்ன பார்க்க வேண்டும்?

“பெரிய சைஸ் குடம் வேண்டும்.”

சரி.

**எவ்வளவு பெரியது?** 😄

இதுதான் முக்கியமான கேள்வி.

“பெரியது” என்பது அளவீடு கிடையாது. அது ஒரு description.

## முதலில் இந்த அளவுகளை கேளுங்கள்

- Height
- Maximum diameter
- Opening diameter
- Capacity
- Approximate weight
- எத்தனை பீஸ்

இவற்றை கேட்டால்தான் இரண்டு குடங்களை நியாயமாக ஒப்பிட முடியும்.

## பெரியது என்றால் அதிக எடைதானா?

அவசியமில்லை.

ஒரே மாதிரி தோன்றும் இரண்டு குடங்களில் ஒன்றின் எடை வேறுபடலாம்.

அதனால்:

**“ஒரு பீஸ் எவ்வளவு எடை?”**

என்று கேட்பது மிகவும் பயனுள்ள கேள்வி.

## கோவில் அல்லது கும்பாபிஷேகத்துக்கா?

அப்படியானால் “பெரியது நல்லது” என்ற logic-ல் வாங்க வேண்டாம்.

எந்த அளவு, எத்தனை குடம் என்பது அந்த கோவில், நிகழ்ச்சி மற்றும் பின்பற்றப்படும் சடங்கு முறையைப் பொறுத்திருக்கலாம்.

தேவையான specification-ஐ priest / temple organiser-ிடம் உறுதி செய்து வாங்குவது பாதுகாப்பானது.

## ஆன்லைனில் வாங்கினால்?

Photo மட்டும் பார்த்து order போடாதீர்கள்.

குறைந்தது:

**Photo + dimensions + approximate weight + capacity + quantity**

கேளுங்கள்.

விற்பவர் இவற்றில் basic details கூட சொல்ல முடியவில்லை என்றால், அது உங்களுக்கு ஒரு useful signal.

“Height ___, weight approximately ___, 50 pieces” என்பது quotation-க்கு உதவும் தகவல்.

## Bottom line

**“பெரிய சைஸ்” என்று வாங்காதீர்கள்.**

உங்களுக்கு தேவையான **அளவு + எடை + பயன்பாடு** தெரிந்து வாங்குங்கள்.
